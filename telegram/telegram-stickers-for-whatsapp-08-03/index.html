Telegram stickers for WhatsApp

ടെലഗ്രാമിലെ സ്റ്റിക്കറുകൾ (animated & non animated) എങ്ങനെ വാട്സാപ്പിലേക്ക് കൊണ്ടുവരാം എന്നു നോക്കാം...

Easiest method:

Install 'Unofficial Telegram stickers for WhatsApp' app from Play Store.
Open it & search for sticker packs]

Screenshots:




വിവിധ packs ൽ നിന്നും ഉള്ള different സ്റ്റിക്കറുകൾ വെച്ച് manually sticker pack create ചെയ്യാൻ...

1. Play Store ൽ നിന്നും Sticker Maker എന്ന ആപ്പ് ഇൻസ്റ്റാൾ ചെയ്യുക.

2. ടെലഗ്രാമിൽ @tgtowabot തുറന്ന് ആവശ്യമുള്ള pack ലെ ഏതെങ്കിലും ഒരു സ്റ്റിക്കർ അതിലേക്ക് അയക്കുക.


3. ബോട്ടിൽ കിട്ടുന്ന '.wastickers' എന്ന ഫയൽ ഡൗൺലോഡ് ചെയ്യുക.


Screenshots 👇

'.wastickers' ഫയൽ '. zip' ആയി rename ചെയ്തതിനു ശേഷം, ഏതെങ്കിലും file manager ഉപയോഗിച്ച് extract ചെയ്ത് അതിൽ നിന്നും ആവശ്യമുള്ള സ്റ്റിക്കറുകൾ (webp) മാത്രമായി എടുത്ത് Sticker Maker ആപ്പ് വഴി custom പാക്കുകൾ ഉണ്ടാക്കാവുന്നതാണ്.
