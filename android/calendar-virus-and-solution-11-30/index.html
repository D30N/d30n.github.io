Calendar virus and solution

എന്താണ് കലണ്ടർ വൈറസ്?

സത്യത്തിൽ ഇത് virus അല്ല. നിങ്ങൾക്ക് വന്ന ഒരു E-mail ലൂടെ നിങ്ങളുടെ Calendar ൽ ഓട്ടോമാറ്റിക്കായി create ആയ കുറേ spam events ആണ് വൈറസ് എന്ന പേരിൽ കാണുന്നത്.


ഫോണിൽ വൈറസ് ഉണ്ടെന്ന് തെറ്റിദ്ധരിപ്പിച്ച് നിങ്ങളെക്കൊണ്ട് ഏതെങ്കിലും anti-virus എന്ന പേരിലുള്ള adwares ഓ spywares ഓ ഒക്കെ ഇൻസ്റ്റാൾ ചെയ്യിക്കൽ ആണ് ഈ fake virus events വഴി അവരുടെ ലക്ഷ്യം.


ഒരൊറ്റ e-mail വഴി നൂറുകണക്കിന് spam events ആണ് ഇങ്ങനെ നമ്മുടെ കലണ്ടറിൽ തനിയെ create ആവുന്നത്. അതുകൊണ്ടുതന്നെ ഓരോന്നായി ഡിലീറ്റ് ചെയ്യുന്നത് ബുദ്ധിമുട്ടാണ്. മാത്രമല്ല Google account ആയിട്ട് sync ആയതുകൊണ്ട് Calendar ആപ്പ് data clear ചെയ്താലോ re-install ചെയ്താലോ ഒന്നും ഇത് പോവില്ല.


എങ്ങനെ remove ചെയ്യാം? (Solution)


Desktop mode ൽ calendar.google.com ഓപ്പൺ ചെയ്ത് അതിലെ settings ൽ event settings എടുക്കുക.


ഇതിൽ 'Automatically add invitations' എന്നത് screenshot ൽ ഉള്ളതുപോലെ No ആക്കിയാൽ ഭാവിയിൽ events automatically add ആവുന്നത് തടയാം.

ശേഷം താഴെ Events from Gmail എന്നത് എടുക്കുക


ഇതിൽ 'Show events automatically created by Gmail in my calendar' എന്നത് screenshot ൽ ഉള്ളതുപോലെ uncheck ചെയ്താൽ already add ആയ spam events ഒക്കെ remove ആവുന്നതാണ്.
